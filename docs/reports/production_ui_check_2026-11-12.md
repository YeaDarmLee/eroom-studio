# 운영 UI 배포 확인 — 2026-11-12

대상: https://eroom-studio.co.kr/

운영 브라우저에서 최근 수정한 공개 화면과 탐색 동작을 확인했다. 운영 코드·데이터는 변경하지 않았고 계약 신청·서명·결제·문자 발송은 수행하지 않았다. 결론은 이번 UI 배포 범위에 한정한다.

## 배포 반영

- /static/css/home.css: HTTP 200. 줄바꿈을 정규화한 내용이 로컬 최신 파일과 일치한다.
- /static/css/branch-detail.css: HTTP 200. 줄바꿈을 정규화한 내용이 로컬 최신 파일과 일치한다.
- 투명 PNG 로고, 본문 중앙 정렬(우측 패딩0), 지점 전체 강조의 background-color 전환, 안내 패널, 테두리 버튼2개, 숫자 타임라인 확인.
- 상단과 모바일 메뉴가 지점 안내 → 이용 안내 → 이용 절차 → 자주 묻는 질문 순서다. 본문의 섹션 순서와 일치한다.
- canonical URL이 실제 .co.kr 도메인이며 로컬 검증 배너는 운영에 표시되지 않는다.

## 실제 화면 및 동작

- 메인 지점 사진6개 로딩 성공. 메인 공실과 공실 바로가기 수치가 모두 1/1/2/2/1/3으로 일치했다(점검 시점 값).
- 390/768/1280/1920px에서 문서 가로 넘침 없음. 콘텐츠 중심과 페이지 중심의 차이0px 확인.
- 좁은 화면 공실 접기, 1920px 공실 상시 표시 확인. 모바일 목록6개 펼침 및 닫기 확인.
- 이용 안내의 버튼 배경/1px 테두리와 실제 목적지 확인. 지점·방 버튼에서 목록 이동 후 지점 상세 진입 확인.
- 모바일 메뉴 항목 선택 후 닫힘, FAQ Enter 키 펼침 확인.
- 봉천점 상세의 정보/사진2열, 갤러리 높이 약391px, object-fit:cover 반영 확인. 사진6개 로딩 성공, 다음 버튼으로2/6 이동 후 ArrowLeft로1/6 복귀 확인.
- 인천점 상세 사진4개 로딩 성공. 모바일 사진 영역 채움 및 문서 가로 넘침 없음 확인.
- 점검 중 수집된 JavaScript error 로그 없음.

## 결과 및 범위

최근 수정 UI의 배포 누락이나 공개 탐색을 막는 신규 문제는 발견하지 못했다. 이는 전체 사이트의 모든 인증 상태·기기·계약 처리에 대한 무결함 보증이 아니다. 별도 테스트 제출 없이 화면·링크·공개 사진과 표시 데이터까지 확인했다.
